# 数据来源记录 / Data Sources

本文件记录本研究所用数据的具体来源、访问链接、访问日期,以及口径说明。核心数据来自泰安市统计局历年发布的《泰安市国民经济和社会发展统计公报》(2016-2025年,共10份)。

---

## ⚠️ 重要发现一:2018-2019年存在官方口径断点(优先处理)

**2019年公报原文(发布于2020-04-01)明确注明:**
"依据第四次经济普查资料,省统计局对全市地区生产总值的初步核算数进行了修订,修订后2018年地区生产总值为2403.9亿元。"

**含义:** 表格中2018年GDP原始数值(3651.5亿元)是**普查修订前**的旧口径,而2019年数值(2663.6亿元)已经是**修订后**的新口径。两者不可直接放入同一条时间序列做回归,否则会出现虚假的"断崖式下降"。

**处理建议:**
- 分析时统一采用修订后口径:2018年应使用 **2403.9亿元**,而非原始的3651.5亿元
- 在正文/附录中注明此次口径调整及来源,不能悄悄替换数字而不说明
- 2016、2017年数据是否也在此次普查中被修订,需要进一步核实(第四次经济普查以2018年为标准时点,理论上不会追溯修订2018年以前的历史数据,但需要在2017年公报原文中确认是否有相关说明)

## ⚠️ 重要发现二:2022年"泰山景区进山人数"缺失是真实的官方缺失

核实2022年公报原文后确认,该年公报**只披露市级"接待国内游客"口径**(5163.9万人次),**没有**单独列出"泰山景区进山人数"这一项。这不是搜索/核实疏漏,而是当年公报本身就没有披露这项细分数据。若要补齐2022年"进山人数",需要另外查找泰山景区管委会或市文旅局的专项通报。

## 二、已核实的关键数据摘录

### 2025年(发布2026-04-14)
- 地区生产总值3803.5亿元,增长5.9%;第三产业增加值1892.2亿元
- 泰山景区进山游客量802.9万人次,"连续3年超过800万人"(意味着2023、2024、2025三年进山人数均超800万,可作为佐证2023年数据的旁证)
- 一般公共预算收入262.0亿元

### 2024年(发布2025-03-31)
- 地区生产总值3622.1亿元,增长5.8%
- 全年接待国内游客9429.43万人次,国内旅游收入902.66亿元
- 泰山景区2024年接待游客941.09万人次,其中进泰山游客806.29万人次
- 外地游客平均停留时间2.12天

### 2022年(发布2023-04-19)
- 地区生产总值3198.1亿元,增长4.3%
- 全年接待国内游客5163.9万人次,国内旅游收入479.3亿元
- 公报未单独披露"泰山景区进山人数"(见上方"重要发现二")
- 注释中提及:"经最终核实,2021年,我市生产总值现价总量为2996.7亿元"——说明2021年数据也经历过"初步核算→最终核实"的常规修订流程,与2018-2019年的普查性重大调整性质不同,幅度较小,可视为正常统计流程

### 2019年(发布2020-04-01)
- 地区生产总值(普查修订前初步核算)2663.6亿元,增长6.3%
- 泰山景区接待进山进景点游客567.9万人,同比增长1.04%
- 游客接待总人数8262.7万人次,国内旅游收入894.4亿元
- 含2018年GDP口径修订的官方说明(见上方"重要发现一")
