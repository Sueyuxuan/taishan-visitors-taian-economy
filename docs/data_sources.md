# 数据来源记录 / Data Sources

本文件记录本研究所用数据的具体来源、访问链接、访问日期,以及口径说明。核心数据来自泰安市统计局历年发布的《泰安市国民经济和社会发展统计公报》(2016-2025年,共10份)。

---

## ⚠️ 重要发现一:2018-2019年存在官方口径断点(优先处理)

**2019年公报原文(发布于2020-04-01)明确注明:**
"依据第四次经济普查资料,省统计局对全市地区生产总值的初步核算数进行了修订,修订后2018年地区生产总值为2403.9亿元。"

**含义:** 表格中2018年GDP原始数值(3651.5亿元)是**普查修订前**的旧口径,而2019年数值(2663.6亿元)已经是**修订后**的新口径。两者不可直接放入同一条时间序列做回归,否则会出现虚假的"断崖式下降"。

**处理建议:**
- 分析时统一采用修订后口径:2018年应使用 **2403.9亿元**,而非原始的3651.5亿元
- 在正文/附录中注明此次口径调整及来源,不能悄悄替换数字而不说明
- 2016、2017年数据是否也在此次普查中被修订,需要进一步核实(第四次经济普查以2018年为标准时点,理论上不会追溯修订2018年以前的历史数据,但需要在2017年公报原文中确认是否有相关说明)

**⚠️ 后续更新(2026-08-24,详见"重要发现三"):** 上述"2403.9亿元"是2019年公报里第四次经济普查后的修订值,但《泰安统计年鉴2025》显示第五次经济普查又对这条序列做了进一步修订,2018年GDP最新应为**2449.0亿元**。GDP这条序列经历了不止一轮修订,以后每次新的经济普查都可能再次改变历史数值。

**⚠️ 再次更新(2026-08-24):** 原计划中"2016、2017年数据是否也被四经普修订"这个待核实项,**在获得年鉴表2-4后已不再是必须核实的问题**——年鉴表2-4一次性给出了2016-2024年在同一次(五经普)修订标准下的完整序列,这9年数字彼此已经可比,不需要再单独追溯每一年历史上分别经过了几次修订。若要在报告中叙述数据修订的历史过程(锦上添花的方法论补充,非必需),可考虑查找早期年鉴(如《泰安统计年鉴2018》)作对比素材,但不影响当前分析可以直接使用年鉴表2-4的现成序列。

## ⚠️ 重要发现二:2022年"泰山景区进山人数"缺失是真实的官方缺失

核实2022年公报原文后确认,该年公报**只披露市级"接待国内游客"口径**(5163.9万人次),**没有**单独列出"泰山景区进山人数"这一项。这不是搜索/核实疏漏,而是当年公报本身就没有披露这项细分数据。若要补齐2022年"进山人数",需要另外查找泰山景区管委会或市文旅局的专项通报。

## ⚠️ 重要发现三:《泰安统计年鉴2025》已获取核实,GDP序列需整体更新(2026-08-24)

年鉴表2-4给出经"第五次全国经济普查"修订后的完整GDP序列(2016-2024),与此前依据公报建立的序列相比,**2019-2022四个年份的数值全部需要更新**(如2021年GDP应为3068.9亿元,而非此前的2996.7亿元)。同时确认年鉴统计表中的"社会消费品零售总额"新序列真实可信,应正式采纳。**2024年国内旅游收入应改用年鉴表8-12的838.7亿元,而非下方"已核实的关键数据摘录"中2024年公报原文的902.66亿元**——原因和判定依据详见 `docs/data_priority_policy.md`。完整核对结果见 `data/taian_development_indicators_v4_20260824.xlsx`。

## 二、已核实的关键数据摘录

### 2025年(发布2026-04-14)
- 地区生产总值3803.5亿元,增长5.9%;第三产业增加值1892.2亿元
- 泰山景区进山游客量802.9万人次,"连续3年超过800万人"(意味着2023、2024、2025三年进山人数均超800万,可作为佐证2023年数据的旁证)
- 一般公共预算收入262.0亿元

### 2024年(发布2025-03-31)
- 地区生产总值3622.1亿元,增长5.8%
- 全年接待国内游客9429.43万人次,国内旅游收入902.66亿元 **(⚠️已被年鉴表8-12修订为838.7亿元,分析时应采用838.7,详见"重要发现三")**
- 泰山景区2024年接待游客941.09万人次,其中进泰山游客806.29万人次
- 外地游客平均停留时间2.12天

### 2022年(发布2023-04-19)
- 地区生产总值3198.1亿元,增长4.3%
- 全年接待国内游客5163.9万人次,国内旅游收入479.3亿元
- 公报未单独披露"泰山景区进山人数"(见上方"重要发现二")
- 注释中提及:"经最终核实,2021年,我市生产总值现价总量为2996.7亿元"——说明2021年数据也经历过"初步核算→最终核实"的常规修订流程,与2018-2019年的普查性重大调整性质不同,幅度较小,可视为正常统计流程

### 2019年(发布2020-04-01)
- 地区生产总值(普查修订前初步核算)2663.6亿元,增长6.3%
- 泰山景区接待进山进景点游客567.9万人,同比增长1.04%
- 游客接待总人数8262.7万人次,国内旅游收入894.4亿元
- 含2018年GDP口径修订的官方说明(见上方"重要发现一")

## 三、统计年鉴 / Statistical Yearbooks

### 《泰安统计年鉴2025》(已获取,已核实,2026-08-24)

- 收录2024年度数据,PDF全文324页,已核实以下关键统计表:
  - 表2-4"主要年份全市生产总值"(GDP及三次产业增加值,五经普修订后完整序列)
  - 表7-1"1991-2024年社会消费品零售总额"
  - 表8-11"1978-2024年旅游情况"、表8-12"国内旅游情况"
- **重要提示:** 年鉴"特载"部分是原样转载当年统计公报,不代表年鉴自己核算的最终值;真正代表年鉴口径的是带编号的正式统计表。两者不一致时以正式统计表为准。
- 年鉴统计表中**未单独列示"泰山景区进山人数""泰山景区门票总收入"**,这两项指标仍需依赖逐年统计公报,2022、2023年缺口依旧未解决。

### 《泰安统计年鉴2024》(已获取,已核实,2026-08-24补充)

- 收录2023年度数据,基于**第四次全国经济普查**口径(尚未反映五经普修订),已核实表2-4"主要年份全市生产总值"、7-1系列"社会消费品零售总额"、8-12"国内旅游情况"三张表。

**⚠️ 重大确认:GDP 2016-2023年确实经历了五经普的进一步整体修订,直接回答了此前"2016、2017是否被修订"的疑问。** 两版年鉴对比(单位:亿元):

| 年份 | 2024年鉴(四经普) | 2025年鉴(五经普) | 差异 |
|---|---|---|---|
| 2016 | 2170.8 | 2206.5 | +35.7 |
| 2017 | 2334.4 | 2371.1 | +36.7 |
| 2018 | 2403.9 | 2449.0 | +45.1 |
| 2019 | 2663.6 | 2723.2 | +59.6 |
| 2020 | 2766.5 | 2844.7 | +78.2 |
| 2021 | 2996.7 | 3068.9 | +72.2 |
| 2022 | 3195.6 | 3270.5 | +74.9 |
| 2023 | 3323.9 | 3448.7 | +124.8 |

结论:2016-2023全部年份都被进一步上修,且修订幅度随年份递增。v4已采用2025年鉴(更新)数值,无需改动,此表作为历史修订过程的证据保留。

**社会消费品零售总额:只有部分年份被修订,不是整条序列都变。** 2016-2018年在两版年鉴中完全一致(886.1/954.2/1016.5),2019-2023年被修订(如2023年从1286.8修订为1363.8)。说明同一次经济普查对不同指标的修订范围不完全相同,不能一概而论。

**国内旅游人数、国内旅游收入(2016-2023部分):** 两版年鉴数字完全一致,未发现修订。

**意外发现:定位到此前一处数据错误的来源。** 2024年鉴"国内旅游情况"表最后一列是"2023年比2022年增长±%",2023年该列数值为70.4(即增长70.4%)。此前某版本数据表中出现过"2024年国内旅游收入=70.4亿元"这一明显错误数字,很可能就是当时把这张表的"增长率"列误读成了"绝对值"列所致。

### 《泰安统计年鉴2017》(覆盖2016年度,已核实,2026-08-24)与《泰安统计年鉴2020》(覆盖2019年度,已核实,2026-08-24)

**⚠️ 重大发现:解开了v1原始数据表中"2016年GDP=3316.8亿元"的来源之谜。** 2017年鉴(2017年8月发布,普查修订前)显示2016年GDP为**3316.79亿元**,与v1原始数字几乎完全一致,证实v1的原始来源真实可靠,并非编造。2020年鉴(2020年10月发布)编辑说明明确写道:"2000年至2018年间的生产总值依据第四次经济普查数据进行了调整",表中显示2016年GDP已变为**2170.83亿元**,与2024年鉴一致。完整四阶段修订时间线及分析见 `docs/data_priority_policy.md` 案例七。
