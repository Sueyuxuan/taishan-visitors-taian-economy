# 后续研究方向

目前的分析主要用的是年度数据，能看出大致趋势，但还有几个问题没回答清楚。我先把想继续研究的内容记在这里，等10月考试季全部结束后，到11月中旬再开始做。其中，月度和假期客流数据已经查过一轮，住宿餐饮、商户收入这两个方向还没实际查。跨城市对比也做了初步查找，不过工作量比较大，到时候需要单独安排时间。

## 一、先补几个关键时段的客流数据

现在用年度数据，只能看到2023年游客数反弹很明显，看不出反弹主要集中在哪几个月，也没法比较1—3月免票期间和其他月份的变化。如果能找到2019—2024年的月度数据，或者至少有季度数据，这部分就能再往下看。

我已经查过泰安市统计局、泰山景区管委会的网站，以及泰安市公共数据开放网（tadata.sd.gov.cn）。目前没有找到连续发布、口径统一的月度客流数据，但能找到一些零散报道，比如2023年8月进山游客138.4万人次、中秋国庆8天46万人次。公共数据开放网上也有泰山景区相关目录，不过目前看到的主要是地理信息，是否还有客流数据，需要继续找。

难点在于，每年报道的月份不一样。即使把这些报道都收集起来，也很难凑齐六年的完整数据，缺的月份不能直接补上。

等11月中旬接着做时，我打算先找几个有资料的时段，比如暑期、国庆假期，看看不同年份能不能对得上，不急着凑出完整的月度曲线。假期天数和统计口径也要一起核对。这样至少能比较几个关键时段，但结果只能说明这些时段的情况，不能拿来概括全年。

## 二、看看能不能找到住宿、餐饮的数据

第三产业增加值包含的行业太多，和游客数放在一起比较，还是有些笼统。我想再找一下住宿、餐饮的数据，看看这些与旅游联系更直接的行业，在这几年里是怎么变化的。

这一部分还没实际查。准备先看泰安统计年鉴里的分行业数据，再查统计局网站，目标是找到2019—2024年住宿和餐饮业增加值，或者规模以上住宿餐饮企业的营业收入。找到什么指标，就按它本身的统计范围来分析，不能把两种指标混着用。

方法上可以沿用前面的做法：以2019年为100计算指数，再比较同比增速，不需要另外加一套方法。

现在还不确定数据能细到什么程度。如果只能找到“批发零售住宿餐饮业”的合并数据，也可以先用，但要说明其中还包括批发和零售，不能把它当成住宿餐饮业的变化。

## 三、游客增加后，本地人的收入有没有跟着增加

这是我最初想问的问题，但现有数据还回答不了。游客数增加、第三产业增加值增长，都不能直接说明景区周边商户或者本地从业者赚得更多了。

要继续回答这个问题，最好能找到景区周边商户的经营资料，或者旅游相关行业的收入、就业数据。我还没有实际查过，后面可以先看看泰安市人社局等部门有没有分行业工资资料，再找新闻报道和政府工作报告里的相关内容。

不过，这一项可能最难做。商户的经营数据通常不公开，即使找到某个行业的平均工资，也很难判断这些人的收入和泰山客流到底有多大关系。

如果最后只能找到商户采访，比如有人说生意比前一年好了，那就把它作为背景材料补充进去。个别商户的感受不能代表所有人，也不能据此得出“游客增加带动了本地居民增收”的结论。

## 四、以后可以和其他城市做一次比较

除了继续补泰安的数据，我还想知道：景区游客数和全市第三产业增加值走势不同步，以及2023年的大幅反弹，是不是在其他城市也能看到。

这个方向已经做过初步查找。等11月中旬恢复研究后，还需要给它单独安排时间：前三项主要是在现有研究上补资料，跨城市比较则要重新收集和核实另一座城市的数据。参照之前整理 `docs/data_priority_policy.md` 时大约三周的工作量，这一项需要留出更完整的一段时间。

### 比较城市先考虑济宁

我最初想到的是曲阜，因为那里有“三孔”景区，也就是孔庙、孔府、孔林。但曲阜是县级市，泰安是地级市，直接比较两地的全市经济数据不太合适。因此，如果比较全市指标，我准备把对象改为曲阜所属的济宁市；如果比较景区客流，仍然可以用“三孔”和泰山的数据。

这样统一了城市的行政层级，但还不能说所有数据都已经可比。两座城市的经济规模、产业结构，以及景区在当地旅游业中的分量，后面都需要考虑。

这里的数据要分开找。济宁市的第三产业增加值、全市游客人次和旅游收入，可以从历年统计公报入手。初步查到的公报还单列了住宿餐饮业增加值，例如2024年为104.7亿元，增长8.3%。如果泰安也能找到同口径数据，就可以进一步比较这一行业的变化。

“三孔”景区自己的游客数，则需要到曲阜市或景区管理机构发布的资料里找。目前查到的济宁市级公报没有单列这个数字。之前看到的2023年“三孔”游客数同比增长约454.5%，来自曲阜市级资料，引用时要写清楚，不能标成济宁市统计公报的数据。泰山这边也一样，要区分景区客流和全市旅游数据。

### 先从两处景区的客流比较做起

“三孔”2023年约454.5%的游客增幅，比泰山的301.3%还高。这让我觉得，2023年的大幅增长可能并不是泰山独有的，值得继续看看其他景区是否也有类似的低基数反弹。但仅凭这两个数字，还不能推到整个山东旅游业。

如果以后继续做，我想先收集“三孔”这几年的游客数，和泰山一样以2019年为100画出变化趋势，看看两条曲线有哪些相似和不同。先把这一项核实清楚，再决定是否继续整理济宁的经济数据。

### 也可以考虑同一年不同城市的比较

目前只有六年的年度数据，样本很少，相邻年份之间也可能存在相关性，所以这次没有做相关系数的显著性检验。

另一个想法是，用山东省统计年鉴里同一年的分市数据，比较16个地级市的旅游收入增速和第三产业增速。这样可以从城市之间的差异入手，补充现在对泰安年度变化的分析。

不过，换成16个城市并不意味着就能直接做显著性检验。各地可能受到共同政策和经济环境的影响，城市之间也可能互相带动；样本仍然不大，指标口径和异常值也需要检查。这个方向可以保留，但能用什么方法、能说明多少问题，要等数据整理出来再判断。

## 11月中旬再接着做

这些方向先记下来，等10月考试季全部结束，11月中旬再开始推进。

到时候我会先做第一项，找几个资料相对齐全的假期或月份进行比较。这一项已经查过，接着做比较有把握。其次是住宿、餐饮数据；商户和从业者收入放在后面，因为目前还不确定能不能找到可用资料。

跨城市比较的工作量更大，等恢复研究后再单独安排。11月中旬先从能做的部分开始，后面根据资料收集的情况，决定每个方向继续做到什么程度。
