## 三、目标与边界

- 每个工作日约1—2小时，共约20小时，包含当天简短记录和文件整理；不含等待官方回复的时间。
- 以2019—2024年为主；2025年仅在附注中保留 provisional 状态，不进入核心计算；2016—2018年不强行拼接景区序列。
- 核心问题：比较泰山景区客流与泰安市第三产业增加值的变化，检查口径和基数如何影响观察。
- 主问题表述：*"2019—2024年，按可比口径或明确标注的表列值，泰山景区客流与泰安市第三产业增加值的变化是否一致？统计口径和比较基期如何影响这一判断？"* 第三产业不是旅游业，两者增速原本就不必相等。
- 全市国内旅游收入/游客人次、城乡收入属于补充分析；不得用全市旅游收入除以景区客流，也不得把全市收入变化归因于景区旅游。
- 不安排回归、因果效应估计或为展示方法而增加的技术。
- 没有查清的口径可以成为正式报告中的限制，不以"所有问题都解决"为完成条件。
- Day 6—8 的计算和图改用 Python 做，不再另外用 Excel 算一遍——这是2026-09-20改的主意，本来想Excel和Python两边都算、互相对一下，后来发现我已经在notebook里跑过一遍，数字都对，两边都算等于重复做同一件事，所以就只留Python这一条。
