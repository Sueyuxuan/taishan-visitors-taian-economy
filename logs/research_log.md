# 研究日志 / Research Log

本文件记录研究过程中的原始观察、信息来源与尚未验证的猜测,目的是保持"观察"与"结论"的清晰界限。

## 2026-08-21

**我的感受:**
我家住在泰山脚下,尤其是周末、小长假和寒暑假,家门口道路两旁停满了外地车辆,小区周边经常交通管制,有些道路限制行驶,泰山进山口经常排长队。

游客数量增长与本地经济价值增长可能不同步。

**为什么值得研究:**

**待办 / 下一步:**

## 2026-08-23

**观察(数据收集结果,来源:泰安市统计局历年国民经济和社会发展统计公报):**
完成第一版数据收集,建立涵盖2016-2025年、五大类共31项指标的数据表(旅游与景区、经济总量与产业增加值、市场消费与财政收支、居民收入与生活水平、人口交通与社会指标)。核心变量"泰山景区进山人数"已获得8年数据(2016-2021、2024、2025),GDP、第三产业增加值、财政收入、城乡居民人均可支配收入等关键经济指标十年数据完整。

**为什么值得记录:**
这是研究核心问题(进山人数与本地经济指标同步性)第一次具备了可以直接开始计算相关性/回归的最小数据集,是一个重要的阶段性节点,值得作为"第一版数据"正式留痕,方便以后与修正版本对比。

**发现的问题(按优先级排列):**

1. **疑似统计口径断点(优先级最高,需先处理再分析):** 2018→2019年GDP由3651.5亿元降至2663.6亿元(降约27%),第二、三产业增加值同期也大幅下降,但同期"GDP实际增速"却记录为正的6.3%,两者矛盾。判断这不是真实经济衰退,而是统计口径在此前后发生重大调整(如经济普查后数据核实)。若不处理直接用于十年回归,会人为制造虚假下降趋势,污染核心分析结果。
2. **核心变量存在关键缺口:** "泰山景区进山人数"缺2022、2023两年,恰好覆盖疫情后恢复期,是分析中最需要观察的一段时间。
3. **部分指标时间序列过于稀疏,基本不可用:** 入境游客人次(仅1年)、泰山景区门票总收入(仅3年)、游客平均停留天数(仅1年),数据点过少,不适合作为时间序列变量,只能作为背景信息引用。
4. **零星缺失,原因待核实:** 社会消费品零售总额(缺2019、2025)、常住人口与城镇化率(缺2020、2021,疑似与人口普查数据核定有关)、公路水路客运总量(2021年后完全消失,疑似该指标被停止统计)。

**猜测(未经验证,无变化):**
游客数量增长与本地经济价值增长可能不同步。

**待办 / 下一步:**
- 优先查证2018-2019年GDP口径调整的官方说明,决定分段处理还是改用增速数据
- 补齐2022、2023年泰山景区进山人数
- 核实常住人口/城镇化率2020-2021缺失原因,以及公路水路客运总量指标是否已停止发布
- 将以上问题同步更新到 docs/data_sources.md 的待办清单
- 若核心断点问题处理完毕,可用现有8年"进山人数"数据先行开展初步相关性检验

## 2026-08-24

**观察(核实泰安市统计局公报原文,来源:2025、2024、2022、2019年公报):**

**为什么值得记录:**
上一条记录中提出的"疑似统计口径断点"猜测,在2019年公报原文中得到了官方证实,不再是猜测。

**关键发现:**
1. **GDP断点已被官方证实:** 2019年公报原文明确注明"依据第四次经济普查资料,省统计局对全市地区生产总值的初步核算数进行了修订,修订后2018年地区生产总值为2403.9亿元"。原始数据表中2018年GDP(3651.5亿元)是普查修订前口径,与2019年及以后的数值不可比,分析时应统一改用修订后口径(2403.9亿元)。

**猜测(更新):**
"游客数量增长与本地经济价值增长可能不同步"这条核心猜测尚未受本次发现影响,不变;但发现二可能提示还需要单独增加一条猜测:"官方公报披露的细分旅游指标(如进山人数)在不同年份的详略程度不一致,可能反映了统计口径/发布制度本身的变化,而非单纯的数据遗漏"。

**待办 / 下一步:**
- 逐一打开剩余6份公报(2023、2021、2020、2018、2017、2016)核实原文
- 下载2020年PDF直链公报,确认文件完整可打开

## 2026-08-24(续)

**观察(核实《泰安统计年鉴2025》原文,建立data_priority_policy.md):**
拿到《泰安统计年鉴2025》PDF后,提取全文并逐表核对GDP(表2-4)、社会消费品零售总额(表7-1)、国内旅游情况(表8-11、8-12)三张关键统计表,与此前多个版本的数据表逐项比对。年鉴"编辑说明"原文确认:"《统计公报》使用数据为快报数或初步统计数,其他各部分为正式年报数据。凡与本《年鉴》数据不一致的以本《年鉴》为准。"

**为什么值得记录:**
这是第一次拿到可以直接仲裁此前多版本数据分歧的权威依据,而且过程中发现了一个此前判断错误的地方,需要如实记录、不能悄悄改正。

**关键发现:**
1. **GDP序列(2016-2023)需要整体更新:** 年鉴表2-4给出经"第五次全国经济普查"修订后的完整序列,2019-2022四个年份的数值与此前所有版本都不一致(如2021年应为3068.9亿元,而非此前一直使用的2996.7亿元)。说明GDP修订是多轮次的(四经普修订过一次,五经普又修订一次),以后如有新的普查,这条序列可能还会再变。
2. **社会消费品零售总额:此前被质疑"来源不明"的新序列被证实完全正确**,与年鉴表7-1精确吻合,应正式采纳,旧序列作废。
3. **⚠️ 自我纠正:2024年国内旅游收入的判断此前是错的。** 上次我认为应以"亲自核实过的公报原文902.66亿元"为准,现在发现年鉴里同时存在902.66(特载转载公报原文)和838.7(表8-12正式统计表,新测算办法)两个数字,按年鉴自身规则应以838.7为准。**这说明"亲自核实过一手来源"不等于"这个来源就是最终权威值"**,还要看该来源本身是初步数还是正式数,公报本身的定位就是初步数。
4. **泰山景区进山人数、门票收入,年鉴统计表中完全没有单独列示**,确认这两项核心指标只能继续依赖逐年公报原文,2022、2023年缺口依旧未解决。
5. 顺带核实并修正了一处此前版本的录入错误:一般公共预算收入增速2021年应为0.006(0.6%),而非0.0006,已按绝对值反推验证。

**猜测(无变化):**
核心猜测不受本次发现影响。

**为什么值得研究/记录这次自我纠正:**
这次发现的"838.7 vs 902.66"案例,连同之前提出的"数据优先级判定规则",一起被写入新建的 docs/data_priority_policy.md,作为规则的实际应用范例。

**待办 / 下一步:**
- 逐一核实剩余年份(2016-2018)是否有更细致的分项数据可与年鉴交叉验证
- 继续寻找2022、2023年泰山景区进山人数的独立可信来源
- v4数据表已整合完成(data/taian_development_indicators_v4_20260824.xlsx),下一步可以基于v4开始数据清洗(data/cleaned/)与初步相关性分析

## 2026-08-24(三)

**观察(数据收集方法论补记):**
表格数据的最初收集使用了Google的Notebook工具辅助整理,形成初版表格后再进行人工核对。这一环节此前没有在日志中记录,现补记:数据流程应为"工具辅助收集 → 人工核对 → 与官方原文逐项核实",最终报告的方法论部分应如实说明这一点。

**为什么值得记录:**
这次对已有数据做了一轮更系统的"修订审计"(Revision Audit),完整过程见 `logs/reflection_2026-08-24_data_rebuild.md`。这里记录审计中发现的、此前尚未处理过的三个新问题。

**关键发现(补充此前未覆盖的问题):**
1. **常住人口存在"时间口径不同"的问题,而不只是数值缺失:** 2020年常住人口数据来自第七次全国人口普查,统计时点是"2020年11月1日",而其他年份用的是"年末常住人口"。这不是"哪个数字错了",而是两类数字测量的时间点本身不同,不能直接当作同一口径比较。需要补充一个 `population_time_basis` 标记字段。
2. **增长率反推绝对值是不可靠的做法,应当避免:** 之前一度考虑用"上一年绝对值×官方增速"反推2025年缺失的社零数值,但发现这种反推依赖的基期数值本身可能已被后续修订(2024年社零从1376.4被年鉴修订为1457.6),反推出的数字会建立在过时的基础上。**结论:凡是缺乏官方直接公布的绝对值,应保留缺失(NA),不用增长率反推填补。**
3. **数据表结构需要升级:** 计划后续为每条数据补充 source、source_type、publication_year、value_method(reported/derived/missing)、revision_status、time_basis、comparability_note 等字段,并建立专门的 `data_conflict_audit.csv` 记录每一次数值修订的前后对比和理由。

**猜测(无变化):**
核心猜测不受本次发现影响。

**待办 / 下一步:**
- 在v4基础上为常住人口指标补充 time_basis 标记
- 检查v4中是否存在任何依赖增长率反推、缺乏官方直接来源的数值,若有则改为缺失(NA)
- 规划建立 data/data_dictionary.md 与 data/data_conflict_audit.csv
- 在 docs/data_priority_policy.md 中补充"自己反推的数据"为最低优先级

## 2026-08-24(四)

**观察(核实《泰安统计年鉴2024》原文):**
获取并核实了《泰安统计年鉴2024》(覆盖2023年度数据,基于第四次经济普查口径),与已核实的《泰安统计年鉴2025》(第五次经济普查口径)逐表对比,直接回答了此前"2016、2017年GDP是否也被普查修订"的疑问。

**为什么值得记录:**
这是第一次拿到两个不同时间点的年鉴版本,可以直接对比同一批指标在两次修订前后的具体数字,而不是只能推测。

**关键发现:**
1. **GDP 2016-2023全部年份都被五经普进一步上修,幅度随年份递增**(2016年+35.7亿元,2023年+124.8亿元)。此前的疑问已有明确答案,不再是待核实事项。
2. **社会消费品零售总额只有2019-2023年被修订,2016-2018年两版年鉴完全一致。** 说明同一次经济普查对不同指标的修订范围不完全相同,不能假设"一次普查=全部历史数据都变"。
3. **国内旅游人数、国内旅游收入(2016-2023部分)两版年鉴完全一致,未发现修订。**
4. **定位到此前一处错误数据的来源:** 2024年鉴"国内旅游情况"表最后一列是"2023年比2022年增长率(70.4%)",此前某版本数据表中"70.4亿元"这一错误数字,很可能是把这一列的增长率误读成了绝对值。

**猜测(无变化):**
核心猜测不受本次发现影响。

**待办 / 下一步:**
- v4表格无需改动(已采用更新的2025年鉴数值)
- 可考虑在最终报告方法论部分,用这次两版年鉴对比作为"数据修订具有渐进性、每次普查影响范围不完全相同"的实证案例

## 2026-08-24(五)

**观察(核实早期年鉴,补全GDP修订时间线):**
获取并核实了《泰安统计年鉴2017》(覆盖2016年度,普查修订前的最早版本)和《泰安统计年鉴2020》(覆盖2019年度,已反映四经普修订)。

**为什么值得记录:**
这次核实解开了一个悬案——v1最初数据表里"2016年GDP=3316.8亿元"这个数字,此前一直不确定是编造还是有出处。

**关键发现:**
1. 2017年鉴显示2016年GDP为3316.79亿元,与v1原始数字几乎完全一致。**证实v1最初的数据来源真实可靠,不是编造,只是后来被两轮经济普查依次修订、没有及时更新。**
2. 2020年鉴编辑说明明确写道"2000年至2018年间的生产总值依据第四次经济普查数据进行了调整",给出的2016-2019年数字(2170.83、2334.42、2403.86、2663.60)与2024年鉴完全一致,确认四经普修订最迟在2020年10月这版年鉴已生效。
3. 完整时间线:3316.79(2017年鉴,原始)→2170.83(2020年鉴,四经普)→2170.8(2024年鉴,沿用)→2206.5(2025年鉴,五经普)。

**猜测(无变化):**
核心猜测不受本次发现影响。

**为什么值得记录这次"悬案解开":**
这个发现提醒我们,数据"来源不明"和"数据错误"是两回事——有时候一个看起来对不上的数字,只是需要找到正确的历史版本去对照,而不是来源本身有问题。这也是为什么保留多版本数据、而不是直接覆盖旧版本,是有价值的做法。

**待办 / 下一步:**
- 如有时间,可核实2021年鉴作为补充节点,进一步细化四经普生效的确切时间窗口
- 可考虑在最终报告方法论部分,用这条完整时间线作为案例,展示对数据可靠性的深入思考

## 2026-08-25(一)

**观察(核对十份公报原文中"进山人数"的具体措辞):**
逐年核实2016-2025年公报原文里"泰山景区进山人数"这一项的具体用词,发现存在四种不同表述,对应两类不同统计范围。

**为什么值得记录:**
此前一直把这条序列当作同一个指标处理,这次核查发现存在隐性的口径切换,此前未曾察觉。

**关键发现:**
1. 2016-2018年公报用词为"泰山景区接待游客X万人次"(配门票收入),属于较宽口径。
2. 2019、2021年用词为"泰山景区接待进山进景点游客X万人",属于较窄口径。
3. **2024年公报同时给出两个数字**("接待游客941.09万人次"和"进泰山游客806.29万人次"),证实这确实是两个不同的统计范围,不是同一概念的不同说法。
4. v4表格目前2016-2018年用的是宽口径(当年未披露窄口径,无法反推统一),2019年之后用的是窄口径,存在隐性口径切换,不是数据错误,而是公报本身逐年措辞不统一。
5. 2020年原文用词尚未核实,2022、2023年公报确认未披露该指标。

**猜测(无变化):**
核心猜测不受本次发现影响,但这个口径问题会影响核心回归分析的严谨性,需要在报告中说明。

**待办 / 下一步:**
- 核实2020年公报原文用词,补全对照表
- 在最终报告方法论部分说明2016-2018与2019年之后口径不完全可比,建议核心回归优先使用2019年之后数据,或对2016-2018单独标注
- 已在v4表格该行备注和data_priority_policy.md案例八中记录此发现

## 2026-08-25(二)

**观察(将进山人数拆分为宽/窄口径两行):**

**为什么值得记录:**
这是把"发现问题"落地为"实际调整数据结构"的一步,不再只是备注提醒,而是让两套口径可以直接独立用于时间序列分析。
